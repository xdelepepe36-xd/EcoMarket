# EcoMarket Setup Skill

Configuración y optimización del proyecto EcoMarket.

## Descripción

Este skill proporciona herramientas para configurar, optimizar y mantener el proyecto EcoMarket, incluyendo configuración de entorno, build scripts, y utilidades de desarrollo.

## Funcionalidades

### Configuración de Entorno
- Configuración de variables de entorno
- Setup de base de datos
- Configuración de rutas estáticas

### Optimización
- Optimización de imágenes
- Minificación de assets
- Configuración de caché

### Desarrollo
- Scripts de desarrollo
- Configuración de hot reload
- Utilidades de debugging

## Uso

Invocar este skill cuando necesites:
- Configurar el entorno de desarrollo
- Optimizar assets del proyecto
- Configurar build scripts
- Setup de herramientas de desarrollo

## Archivos Relacionados

- `app.py` - Aplicación principal Flask
- `requirements.txt` - Dependencias Python
- `static/` - Archivos estáticos
- `templates/` - Plantillas HTML
